Class Reference

Simulation

Main

Source: conv/main.ts

Static main loop controller that ties together view clearing, simulation, effect rendering, GUI rendering, and mouse handling.

Related concepts: View, Camera, Sim, Effects, GUI, Events.
Constructor

None. Use static members only.

Methods
  • run(fps = 0): initializes loop state and starts the engine.
  • loop(startTime?): runs one loop iteration and schedules the next frame.
  • doWork(): performs one frame of engine work.
  • moveCameraAndSimObjects(dynamicOnScreen, staticOnScreen): updates camera motion and moves eligible objects.
  • renderSimAndEffects(dynamicOnScreen, staticOnScreen): renders visible objects and both effect layers.
  • checkMouse(): routes mouse checks through GUI and clickable sim objects.
  • showDelta(): draws frame diagnostics.
  • setPaused(paused): updates pause state.
Typical use

Set Main.creatorsFunction for per-frame game logic, then start the engine with Main.run(fps).

Sim

Source: conv/sim.ts

Static registry for all simulation objects plus quadtree maintenance and dynamic collision resolution.

Related concepts: SimObject, QuadTree, RectBounds, Vec.
Constructor

None. Use static members only.

Methods
  • add(obj, position, rotation = 0): inserts a finalized SimObject into the simulation.
  • get(name): returns a registered object by name.
  • remove(name): removes an object from all registries.
  • rebuildQuadTrees(): rebuilds dynamic quadtree state and refreshes static state when needed.
  • detectDynamicCollisions(): returns overlapping dynamic collision pairs.
  • resolveDynamicCollisions(elasticity): applies elastic collision response.
Notes

Objects must be finalized before insertion. Static and dynamic objects are stored in separate quadtrees.

SimObject

Source: conv/simobject.ts

Top-level simulation entity that owns a hierarchy of Part instances and carries movement, collision, and interaction state.

Related concepts: Part, Polygon, Button, Sim, Vec, Mien.
Constructor
  • new SimObject(name, canMove = 'always', mass = 1)
  • name: unique object name in Sim
  • canMove: 'always', 'never', or 'onscreen'
  • mass: used by applyForce(...) and collision response
Accessors
  • localPosition: fixed root-local origin
  • localRotation: fixed root-local rotation
  • position: alias for worldPosition
  • parts: direct child parts of the root body
Methods
  • finalize(): caches part layout and marks the object ready for Sim.add(...).
  • getPart(name): returns a named part or undefined.
  • isMouseIn(simObject): static helper for radius-based mouse hit testing.
  • move(delta): advances position and rotation.
  • applyForce(force, delta): changes velocity using mass-scaled acceleration.
  • applyCollisionFrom(other, velocity, correction): applies resolved collision state.
  • render(): renders every finalized part.

Part

Source: conv/simobject.ts

Single renderable body segment within a SimObject hierarchy. Parts can have child parts and local spin.

Related concepts: SimObject, Polygon, Button, Camera, View.
Constructor
  • new Part(name, polygons)
  • name: part identifier
  • polygons: one Polygon or an array of polygons
Accessors
  • worldPosition: part position in world space
  • worldRotation: part rotation in world space
Methods
  • clone(): returns a new part with the same name and polygon references.
  • calculateLocals(): recomputes local position and rotation.
  • addTo(parent, offset, rotation = 0, depthModifier = 0): attaches the part to a parent.
  • get(name): recursively finds a child part.
  • getWorldPolygons(): converts polygon points into screen-ready coordinates.

QuadTree

Source: conv/quadtree.ts

Spatial index used for visibility queries and dynamic collision pair generation.

Related concepts: SimObject, RectBounds, Sim.
Constructor
  • new QuadTree(bounds, capacity = 4)
  • bounds: world-space RectBounds
  • capacity: number of objects allowed before subdivision
Methods
  • clear(): empties the node and releases children.
  • init(bounds, capacity): reinitializes the node.
  • findInRange(rectBounds, found = []): returns objects overlapping the search area.
  • findCollisionPairs(): returns unique overlapping collidable pairs.
  • insert(object): inserts a SimObject.
  • subdivide(): creates child quadrants.
Notes

Dynamic and static simulation registries each maintain their own quadtree in Sim.

Rendering and Effects

View

Source: conv/view.ts

Static canvas, mouse, and world/screen coordinate conversion layer.

Related concepts: Camera, SimObject, Button, GUI, Text.
Constructor

None. Use static members only.

Methods
  • initialize(): creates the canvas and binds DOM event handlers.
  • screenToWorld(x, y): converts screen coordinates to world coordinates.
  • mouseToWorld(): converts current mouse position to world coordinates.
  • worldToScreen(w): converts a world point to screen coordinates.
  • canSee(point, radius?): checks visibility against camera bounds.
  • clear(): fills the canvas with the current background color.
  • handleCameraDrag(mouseInteractedWithSomething): manages drag-to-pan behavior.
  • cancelDrag(): clears drag state.
  • resizeCanvas(): updates canvas size and screen center.
Notes

Camera and View are tightly coupled and share coordinate transforms.

Camera

Source: conv/view.ts

Static camera controller for world position, zoom, anchoring, and animated pans.

Related concepts: View, SimObject, RectBounds, Main.
Constructor

None. Use static members only.

Accessors
  • zoom: current zoom level
  • zoomFactor: wheel-zoom divisor
  • x, y: camera center in world space
  • cameraBounds: current visible world rectangle
  • canMove: false while anchored or panning
  • isPanning: true during pan animation
Methods
  • setCameraBounds(): recomputes the visible world bounds.
  • anchorTo(simObject): locks the camera to a point-like object.
  • freeAnchor(): removes the anchor and stops panning.
  • panTo(x, y, zoom?): animates the camera toward a target.
  • move(): advances the current pan animation.
  • moveToUpperLeftScreen(): pans toward the current upper-left screen corner.

Effects

Source: conv/effects.ts

Static container for transient visual effects.

Related concepts: CircleEffect, RadialEffect, LineEffect, ParticleEffect, Main.
Constructor

None. Use static members only.

Methods
  • addForeground(effect): adds one effect or an array of effects to the foreground layer.
  • addBackground(effect): adds one effect or an array of effects to the background layer.
  • renderForeground(): renders active foreground effects and removes expired ones.
  • renderBackground(): renders active background effects and removes expired ones.
Notes

Effects are short-lived renderable objects whose render() method returns true while they remain active.

CircleEffect

Source: conv/circle-effect.ts

Filled expanding circle or arc effect rendered in the background or foreground effect layer.

Related concepts: Effects, SimObject, View, Camera, Main.
Constructor
  • new CircleEffect(anchor, initialRadius, expansionRate, color, durationInSeconds, startAngle?, endAngle?)
  • anchor: world point or SimObject
  • initialRadius: starting radius in world units
  • expansionRate: radius growth per second
  • color: base CSS color string
  • durationInSeconds: total lifetime
  • startAngle, endAngle: optional arc limits in degrees
Methods
  • render(): draws one frame, advances lifetime, and reports whether the effect should remain active.
Notes

When the anchor is a SimObject, the effect follows the object while it lives.

RadialEffect

Source: conv/radial-effect.ts

Expanding stroked circle or arc effect.

Related concepts: Effects, CircleEffect, SimObject, Main.
Constructor

new RadialEffect(anchor, initialRadius, expansionRate, color, thickness, durationInSeconds, startAngle?, endAngle?)

Methods
  • render(): draws one frame, expands the radius, fades the stroke, and returns true while active.
Notes

Use this when you want an outline ring instead of the filled disc produced by CircleEffect.

LineEffect

Source: conv/line-effect.ts

Transient line drawn between two points or two moving objects.

Related concepts: Effects, SimObject, View, Camera.
Constructor

new LineEffect(startAnchor, endAnchor, color, thickness, durationInSeconds)

Methods
  • render(): draws one frame, decreases lifetime, and returns true while active.
Notes

Anchors can be points or SimObject instances, so the line can follow moving objects.

ParticleEffect

Source: conv/particle-effect.ts

Small square particle that drifts with its own velocity while staying anchored to a point or object origin.

Related concepts: Effects, SimObject, Rnd, Vec, Main.
Constructor

new ParticleEffect(anchor, velocity, color, thickness, durationInSeconds)

Methods
  • render(): draws one particle frame, advances offset and lifetime, and returns true while active.
  • generateGroup(origin, angle, angleSpan, velMin, velMax, thickness, color, groupSize, durMin, durMax): creates randomized particle bursts.
Notes

generateGroup(...) is the easiest way to build plume and impact effects.

Polygon

Source: conv/polygon.ts

Basic polygon geometry plus helpers for generating and transforming shapes.

Related concepts: Part, Mien, Vec.
Constructor
  • new Polygon(points, mien = Mien.Gray)
  • points: polygon vertices in local space
  • mien: render style palette
Methods
  • fromArray(points, mien = Mien.Gray): builds a polygon from numeric coordinates.
  • translate(polygon, vector): returns a translated copy.
  • flipVertical(polygon): returns a vertically mirrored copy.
  • flipHorizontal(polygon): returns a horizontally mirrored copy.
  • scale(polygon, scale): returns a scaled copy.
  • rotate(polygon, angle): returns a rotated copy.
  • regular(sides, radius, mien = Mien.Gray): builds a regular polygon centered at the origin.
Notes

Most demos use Polygon.regular(...) for quick bodies, then attach the result to a Part.

Accessors

GUI and Interaction

GUI

Source: conv/gui.ts

Static registry and renderer for all GUI panels and elements.

Related concepts: GUIPanel, GUIElement, Button, Mien, View, Main.
Constructor

None. Use static members only.

Methods
  • initialize(lineSpace = 1, margin = 3, mien = Mien.Green): resets GUI state.
  • configurePauseHandlers(getPaused, setPaused): hooks modal behavior into pause state.
  • hasModal(): reports whether a modal panel is active.
  • getInteractivePanels(): returns visible panels that should receive mouse interaction.
  • showModal(panel, onResolve): displays a modal panel and optionally pauses the simulation.
  • resolveModal(value): closes the active modal and resolves it.
  • isMouseIn(element): checks whether the mouse is inside a GUI element's bounds.
  • render(): renders non-modal panels, overlay, and modal panel.
  • removePanel(panel): removes a panel and dependent subpanels.
Notes

Modal support is demonstrated in test/10_modal_gui.js.

GUIPanel

Source: conv/gui.ts

Container that lays out GUIElement instances vertically or horizontally and may be anchored to screen space, another GUI element, or a SimObject.

Related concepts: GUI, GUIElement, Button, Mien, SimObject, View.
Constructor
  • new GUIPanel(anchor, direction, constraint, flex = false, visible = true, mien?)
  • anchor: screen point, GUIElement, or SimObject
  • direction: 'vertical' or 'horizontal'
  • constraint: base element size { width, height }
  • flex: allows content-sized layout in the layout direction
  • visible: initial visibility
Accessors
  • position: current anchor position in screen coordinates
Methods
  • show(), isVisible(), hide()
  • drawConnector(corner, size, direction)
  • render()
  • addText(...), addButton(...), addList(...), addGraph(...)
Notes

Panels can be anchored to screen space or to moving world objects through SimObject.

Related concepts: Button, GUIElement, Main.

Typical Engine Flow

  1. Create SimObject instances.
  2. Build each object's body with Part and Polygon.
  3. Call finalize() on each object.
  4. Insert objects with Sim.add(...).
  5. Assign Main.creatorsFunction if you want per-frame spawning or gameplay logic.
  6. Start the loop with Main.run(fps).

The smallest example of that flow is test/1_parts.js, while richer examples are test/12_stress_test.js, test/17_warship_duel.js, and test/18_moving_warship_duel.js.
